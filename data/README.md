# Dataset

This folder holds the 15-second time-based flow feature file of the **ISCX VPN-nonVPN (ISCXVPN2016)** dataset, which the project results use: `TimeBasedFeatures-Dataset-15s-VPN.csv` (18,758 rows and 24 columns; 9,793 VPN and 8,965 Non-VPN).

The dataset was created by the Canadian Institute for Cybersecurity at the University of New Brunswick and is not our work. Official source, including the 30, 60 and 120 second files: https://www.unb.ca/cic/datasets/vpn.html

If you use the dataset, cite: G. Draper-Gil, A. H. Lashkari, M. S. I. Mamun, and A. A. Ghorbani, "Characterization of Encrypted and VPN Traffic Using Time-Related Features," in *Proc. ICISSP*, 2016, pp. 407-414.
